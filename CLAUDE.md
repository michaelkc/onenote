# P3X OneNote

Coding-agent guidance lives in [AGENTS.md](AGENTS.md) — read it before working in
this repo. It documents the **global note search** feature (the actively developed
part of this fork): architecture map, invariants that are easy to break, auth flow,
verification workflow, and known quirks.

The original P3X OneNote wrapper featureset is **out of scope** — do not change it
unless the search feature directly requires it.
